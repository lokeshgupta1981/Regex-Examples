# Regex for Alphanumeric Characters in Java (With Examples)

Source code for the article [Regex for Alphanumeric Characters in Java (With Examples)](https://howtodoinjava.com/java/regex/regex-alphanumeric-characters/).

## Versions

- Java 25 (LTS)
- Maven 3.9 or newer
- JUnit 6.1.3

## Run

```bash
mvn -q compile exec:java   # prints every example with its result
mvn test                   # runs the tests that check each example
```

## Files

| File | What it shows |
|------|---------------|
| `src/main/java/com/howtodoinjava/regex/Alphanumeric.java` | Every alphanumeric check from the article, printed with its result |
| `src/test/java/com/howtodoinjava/regex/AlphanumericTest.java` | Tests for valid and invalid samples, length limits, variants, the letter-and-digit rule, Unicode classes, cleanup and the regex-free check |

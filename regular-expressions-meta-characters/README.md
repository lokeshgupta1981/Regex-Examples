# Java Regex Metacharacters: Complete List With Examples

Source code for the article [Java Regex Metacharacters: Complete List With Examples](https://howtodoinjava.com/java/regex/regular-expressions-meta-characters/).

## Versions

- Java 25 (LTS)
- Maven 3.9 or newer
- JUnit 6.1.3

## Run

```bash
mvn -q compile exec:java   # prints every example with its result
mvn test                   # runs the tests that check each example
```

## Files

| File | What it shows |
|------|---------------|
| `src/main/java/com/howtodoinjava/regex/MetaCharacters.java` | Every metacharacter example from the article, printed with its result |
| `src/test/java/com/howtodoinjava/regex/MetaCharactersTest.java` | Tests for the dot, character classes, quantifiers, anchors, groups, lookaround, escaping, split(), replacement strings, invalid patterns and inline flags |

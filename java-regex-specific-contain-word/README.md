# Regex to Match an Exact Word in Java (and Contains Word)

Source code for the article [Regex to Match an Exact Word in Java (and Contains Word)](https://howtodoinjava.com/java/regex/java-regex-specific-contain-word/).

## Versions

- Java 25 (LTS)
- Maven 3.9 or newer
- JUnit 6.1.3

## Run

```bash
mvn -q compile exec:java   # prints every example with its result
mvn test                   # runs the tests that check each example
```

## Files

| File | What it shows |
|------|---------------|
| `src/main/java/com/howtodoinjava/regex/ExactWord.java` | Every exact-word and contains-word example from the article, printed with its result |
| `src/test/java/com/howtodoinjava/regex/ExactWordTest.java` | Tests for exact words, case-insensitive search, substrings, any or all of several words, quoted user input, counting, replacing and the String alternatives |

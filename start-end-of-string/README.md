# Regex End of Line and Start of Line in Java (^, $)

Source code for the article [Regex End of Line and Start of Line in Java (^, $)](https://howtodoinjava.com/java/regex/start-end-of-string/).

## Versions

- Java 25 (LTS)
- Maven 3.9 or newer
- JUnit 6.1.3

## Run

```bash
mvn -q compile exec:java   # prints every example with its result
mvn test                   # runs the tests that check each example
```

## Files

| File | What it shows |
|------|---------------|
| `src/main/java/com/howtodoinjava/regex/StartEndOfString.java` | Every anchor example from the article, printed with its result |
| `src/test/java/com/howtodoinjava/regex/StartEndOfStringTest.java` | Tests for the start and end anchors, MULTILINE mode, the input anchors, the trailing line break and line terminators |
